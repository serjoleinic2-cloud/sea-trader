# Проверки Sea Trader

Собственные TestBase/TestRunner, без внешнего тестового плагина.

## Безопасный запуск на Windows

```powershell
.\tests\run_tests.ps1 -GodotBin 'C:\path\to\Godot_v4.7.2-stable_win64_console.exe'
```

Скрипт копирует текущий код без `.git` и `.godot` во временную папку и задаёт
уникальный каталог сохранений через `override.cfg`. Копия проекта и импорт находятся
в `work/verification-temp/` рядом с проектом (на D: в рабочей установке), а не на C:.
Копируются отслеживаемые Git и новые неигнорируемые файлы с текущими правками;
игнорируемые локальные модели, Blender-исходники и `work/` не копируются.
Обычные сохранения и
проект не изменяются. Логи и тестовая копия остаются по выведенным путям.
Проверяются чистый импорт, завершение обоих наборов, код выхода и ошибки
скриптов; зависший процесс останавливается по тайм-ауту.

## Безопасный запуск на Linux

```bash
GODOT_BIN=/absolute/path/to/godot bash tests/run_tests.sh
```

Скрипт создаёт отдельный XDG_DATA_HOME, импортирует проект и запускает test_runner.tscn и runtime_smoke.tscn. Игровые сохранения не используются. Временные данные и логи сохраняются для диагностики. Не выставлять SEA_TRADER_ISOLATED_TESTS вручную в каталоге обычного игрока.

Ненулевой код процесса, упавшая проверка, SCRIPT ERROR или Parse Error означают отказ. Некоторые тесты специально подают повреждённые и неподдерживаемые сохранения; сообщения SaveSystem об их отклонении ожидаемы.

## Покрытие

`tests/trade_outfitting_smoke.tscn` проверяет торговые слоты настоящими событиями
мыши, включая закрытие поверх уведомления, большие карточки, найм, резерв,
обновление кандидатов, свитки и Esc. Запускать только в изолированном тестовом
профиле. `SEA_TRADER_SLOT_AUDIT_EXISTING=1` использует уже скопированное в этот
профиль сохранение вместо стандартного состояния; в конце тестовое сохранение удаляется.

- Мир из seed, данные GameState, события и сохранения.
- Миграция, резервные копии, отказ без перезаписи неизвестной версии/корабля.
- Физика, управление, расход топлива и основной автопилот.
- Цены, спрос, однократная выплата, груз при отказе, повторные рейсы и контракты.
- Карьера и отсутствие опыта за перекладывание товаров.
- Единый каталог, защита кэша, валидация определений и графа модулей.
- Генерация челленджей, baseline, сроки, повторное получение, запас наград.
- Активация бустов, премиум, сборка артефактов, эффект на скорость и сохранение.
- Полная сцена: кнопка запуска рейса, движение, перезагрузка, склад, принятие челленджа и окна в двух размерах viewport.

## Подтверждение

Автоматический запуск выполнен в Godot 4.4.1 headless на Linux 19 сентября 2026 года. Эти проверки подтверждают игровую логику и геометрию контролов; внешний вид Windows, Android-экспорт и датчики на телефоне проверяются отдельно.


## Игровое меню и карта — 16 октября 2026

`tests/game_menu_smoke.tscn` запускает настоящую сцену игры в изолированной
тестовой копии. Проверяет компактную стройку, выбор курса без закрытия карты,
три ступени качества воды, масштаб 3D, игровые переключатели VSync,
сглаживания и облаков, звук, паузу, ручное сохранение и реальную перезагрузку
сцены. `SEA_TRADER_UI_CAPTURE=1` дополнительно сохраняет
два графических снимка в тестовой копии; для этого нужен графический запуск.
В существующем тестовом профиле можно повторять эту сцену без создания
новой копии проекта или нового каталога сохранений.
