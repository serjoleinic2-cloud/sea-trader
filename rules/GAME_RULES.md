# GAME RULES

> Decisions that cannot be changed without explicit owner approval.
> Last Updated: 2026-08-23 | Version: 0.1.0

---

## NON-NEGOTIABLE RULES

These rules define what the game fundamentally is. Changing them changes the game.

### Core
1. **Offline-first.** The game must function without any internet connection. No features may require a server.
2. **Top-down 2D gameplay.** The main game view is top-down. No 3D, no side-scrolling.
3. **Player manually controls their main ship.** The player always personally navigates their primary vessel during active play.

### Controls
4. **Primary control method is phone tilt.** Tilt forward = throttle. Tilt backward = brake. Tilt left/right = steering.
5. **Navigation compass arrow is a guide only.** The arrow shows direction and distance to destination. It does not steer the ship automatically.

### Risk and Reward
6. **Speed affects reward.** Faster delivery = higher contract reward.
7. **High speed increases damage risk.** Speed is a conscious tradeoff, not a free advantage.
8. **Damage has real gameplay consequences.** Damaged components must meaningfully reduce ship capability.

### Economy
9. **Economy must make sense.** Prices, costs, and rewards must be internally consistent and balanced.
10. **Progression must open new opportunities.** Upgrades and development must unlock meaningfully better gameplay, not just numbers.

### Monetization
11. **Ads must not interrupt active ship control.** No ads during sailing, navigation, or combat.
12. **Monetization must not destroy free gameplay.** A player spending no money must be able to progress through all core content.
13. **No pay-to-win.** Paid items are cosmetic or convenience, not gameplay advantages.
