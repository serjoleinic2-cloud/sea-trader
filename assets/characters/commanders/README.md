# Портреты командиров гарнизона

Каждая раса хранится в отдельной папке, в каждой папке — три независимых портрета кандидатов. Каталог путей находится в `data/combat/commander_portraits.json`; интерфейс выбирает портрет только из списка выбранной расы. В пределах гарнизона портреты главного командира и заместителя не повторяются.

Папки:

- `humans/` — люди
- `nerids/` — нериды
- `surr/` — сурры
- `meridians/` — меридианы
- `aery/` — аэрии
- `crystari/` — кристари

Чтобы заменить персонажа, положите новый PNG в папку нужной расы под именем `portrait_01.png`, `portrait_02.png` или `portrait_03.png`. Размеры портретов внутри расы должны совпадать; кадрирование и назначение файлов задаются каталогом JSON.

Источник первой версии набора — `../crew/crew_portrait_atlas.png`. Раскладка всех персонажей теперь разделена на файлы, чтобы их можно было менять независимо.
