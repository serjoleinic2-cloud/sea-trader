# Исходные референсы рас

Эти пять WebP сохранены как исходные художественные референсы владельца.
Файлы в коммите `994d92e` обрезаны: длина каждого меньше размера, указанного
в заголовке RIFF, поэтому Godot и Pillow не могут их декодировать.

Папка исключена из импорта через `.gdignore`. Она не используется для игровых
портретов: галерея и досье берут проверенные изображения из
`assets/characters/captains/`. Исходные файлы сохранены без перезаписи;
заменять их следует только полными оригиналами.
