# 3D-модели мира Sea Trader

Добавляй сюда собственные модели и регистрируй их в `data/world/world_asset_catalog.json`.

Поддерживаются сцены Godot `.tscn` и импортированные модели `.glb`. Выбор варианта детерминирован по ID объекта, поэтому он не меняется после перезапуска. Пустая категория использует схематическую модель Godot.

## Каталоги

- `islands/` — острова, скалы и береговые формы.
- `ports/` — портовые сцены с пирсом и бухтой.
- `ships/` — корабли.
- `buildings/` — здания портов и базы.

Добавь файл в подходящую папку, затем добавь запись в массив категории каталога моделей. Укажи базовый размер модели в метрах: игровой код подгонит масштаб под объект. Начало сцены острова считается центром берега. Модель порта должна быть собрана вокруг собственного причала.
