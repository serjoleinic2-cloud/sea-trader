# Горная бухта — Blender study

Сцена: `source/karst_cove.blend`. Исходник генерации и художественных параметров:
`tools/art/build_karst_cove.py`. Масштаб — метры, вертикаль — Z.

После замечания владельца вытянутые отдельные скалы заменены цельной горной
грядой: основной хребет, неравные вершины, седловины, диагональные боковые
отроги и широкие основания. Бухта открыта с одной стороны.

В коллекциях отдельно находятся рельеф, растительность, тропа, маяк, причал,
корабль для сравнения масштаба, вода и освещение. Основной рельеф — замкнутая
редактируемая сетка с дном ниже воды. Деревья используют общие редактируемые
меши; оригиналы находятся в скрытой коллекции `07`. Каменные текстуры упакованы
в blend. Вода — отдельная плоскость для просмотра, её можно скрыть.

Камера `01` показывает остров целиком, `02` — подход с моря.
Проверочный рендер: `outputs/islands/karst_cove/karst_cove_approach.png`.
Это отдельный образец для просмотра владельцем. Он ещё не подключён к
игровой генерации, коллизиям и навигации.

## Город и low-poly лес

`source/karst_cove_city.blend` — вариант с небольшими домами людей, портовыми
зданиями, улицами, торговыми навесами, причалами и флагами с существующим гербом.
Обычные дома имеют высоту крыши около 7 м, общественные — до 10 м, чтобы
сохранялось ощущение размеров горного острова.

В этой версии весь видимый лес заменён low-poly деревьями (около 250
треугольников на дерево, семь общих мешей, один материал с цветами вершин).
В скрытой коллекции `11` лежат дополнительные упрощения деревьев и рельефа.
Связанные экземпляры домов используют шесть редактируемых прототипов в `10`.
Сборщик: `tools/art/populate_mountain_cove.py`; исходный природный остров он
не перезаписывает. Точные счётчики: `performance_geometry.json`.

Размер геометрии не является замером FPS. Для игрового подключения ещё нужны
переключение LOD по расстоянию, пространственные группы MultiMesh, отсечение
невидимых участков, настройка теней и проверка в Godot на целевом оборудовании.
