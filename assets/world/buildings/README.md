# Здания базы

Каждый тип из `data/ports/building_catalog.json` имеет свою папку: `dock`, `warehouse`, `workshop`, `market`, `shipyard`, `mage_guild`, `fishing_wharf`, `timber_yard`.

В каждой `levels/` хранит 30 самостоятельных GLB, `source/` — Blender-библиотеку. `island_tower/` содержит универсальную башню. Пути и размещение редактируются в `data/world/home_base_visuals.json`. Полный процесс описан в `assets/world/ports/home_base/README.md`.
