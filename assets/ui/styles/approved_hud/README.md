# Утверждённый HUD — 2 октября 2026

Источник: `assets/ui/concepts/main_hud_concept_v1.png`, утверждённый владельцем.
Нарезка: `tools/art/slice_approved_hud.py` (Python + Pillow).

- `button_frame.png`: исходная нарисованная латунная рамка, очищенная от подписи и иконки; используется как девятисегментная текстура кнопок и окон.
- `chart_backdrop.png`: фон из верхнего фрагмента навигационной карты.
- Остальные PNG: отдельные вырезанные иконки меню и пяти основных ресурсов.

Текст и значения рисует Godot. Исходный арт целиком не подставляется вместо
игрового мира. На широком экране HUD занимает один ряд, при нехватке ширины
ресурсы переносятся под меню; дополнительные товары открываются отдельным списком.
Кабинет сохраняет полный арт каюты и прозрачную панель текста слева.

Проверочные кадры настоящей сцены: `outputs/ui/approved-hud/`.
`tools/ui/preview_hud.tscn` запускать только в копии проекта с отдельными
сохранениями и `SEA_TRADER_ISOLATED_TESTS=1`.
