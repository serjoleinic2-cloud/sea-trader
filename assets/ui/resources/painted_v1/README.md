# Мини-арты товаров и ресурсов

12 отдельных прозрачных PNG, 256×256. Созданы встроенным `image_gen.imagegen`:
десять товаров из `data/resources/goods_catalog.json`, монеты и магические осколки.
Полный точный набор промптов находится в `prompts.json`.

Исходники высокого разрешения хранятся только локально в
`D:\sea-trader\work\art\resource_icons\painted_v1\` (Git игнорирует `work/`).
Повторная упаковка утверждённых исходников:
Godot `--headless --path D:\sea-trader --script res://tools/art/package_resource_icons.gd`.
Скрипт уменьшает копии с сохранением альфы и не меняет исходники.

Единый загрузчик: `systems/ui/resource_item_art.gd`. Набор используют рынок,
верхние показатели ресурсов и таблица дополнительных материалов «Ещё».
Имена PNG совпадают с ID товара/валюты; старые нарезанные иконки HUD сохранены
как резервный набор. Для замены конкретного мини-арта достаточно заменить
его PNG, не меняя экономику или ID товара.
